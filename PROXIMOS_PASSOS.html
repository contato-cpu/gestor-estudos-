Gestor de Estudos - Cadernos Sistematizados

Banco Neon ✅ configurado | .env ✅ pronto

O que já está pronto:

Projeto Next.js criado (30 arquivos, 5 telas)
Banco PostgreSQL no Neon (São Paulo)
Arquivo .env configurado com connection string
Schema do banco definido (12 tabelas)
Seed de disciplinas e editais preparado
1

Instalar Node.js (se ainda não tem)

Baixe e instale o Node.js versão LTS:

https://nodejs.org/pt → Botão verde "LTS"

Depois de instalar, feche e abra o terminal (PowerShell ou CMD) novamente.
2

Abrir o terminal na pasta do projeto

Abra o PowerShell ou CMD e navegue até a pasta do projeto:

Navegar até o projeto:
cd "C:\caminho\para\cadernos 2026 agente\gestor-estudos-cs"
Substitua "C:\caminho\para\" pelo caminho real da sua pasta. Você pode arrastar a pasta para o terminal para colar o caminho.
3

Instalar dependências

Se existir uma pasta node_modules dentro de gestor-estudos-cs, delete ela primeiro (clique direito → Excluir no Explorador de Arquivos).
Instalar pacotes do projeto:
npm install

Aguarde finalizar (pode levar 1-2 minutos). Vai aparecer "added X packages".

4

Criar tabelas no banco de dados

Este comando lê o schema e cria todas as 12 tabelas no Neon:

Criar tabelas:
npx prisma db push

Deve aparecer: Your database is now in sync with your Prisma schema.

Se aparecer "Do you want to continue?", digite y e Enter.
5

Popular dados iniciais (seed)

Cadastra as 29 disciplinas e 3 editais no banco:

Rodar seed:
npm run seed

Deve aparecer: ✅ 29 disciplinas cadastradas e ✅ 3 editais cadastrados

6

Testar localmente

Iniciar o servidor de desenvolvimento:
npm run dev

Abra o navegador em: http://localhost:3000

Se tudo correu bem, você verá a tela de login do Gestor de Estudos! 🎓

Para parar o servidor: Ctrl + C no terminal.

7

Deploy no Vercel (depois)

Quando estiver satisfeita com o teste local:

Instalar Git (se não tem):
winget install Git.Git
Inicializar repositório:
git init && git add . && git commit -m "Primeiro commit - Gestor de Estudos CS"

Depois: criar repositório no GitHub, fazer push, e conectar ao Vercel.

Podemos fazer essa parte juntos quando você quiser!
8

Processar PDFs com IA (depois)

Para gerar as ~18.000 questões a partir dos seus 109 PDFs:

Adicionar chave da OpenAI no .env:
OPENAI_API_KEY="sk-sua-chave-aqui"
Processar PDFs:
npm run process-pdfs -- "C:\caminho\para\seus\pdfs"
Precisa de uma chave da OpenAI (custa ~R$120 para processar todos os 109 PDFs). Podemos configurar isso juntos depois.
