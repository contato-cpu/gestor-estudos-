Pré-requisitos

5 min

Você precisa ter instalado no seu computador:

📦 Node.js (v18+) 🔧 Git

Para verificar se já tem:

node --version
git --version
Você já instalou o Git e Node.js na sessão anterior, então deve estar tudo pronto!
1

Criar Banco de Dados (Neon)

3 min

🌐 Abrir neon.tech

  1. Crie uma conta gratuita (pode usar Google/GitHub)
  2. Clique em "Create a project"
  3. Nome do projeto: gestor-estudos-cs
  4. Região: São Paulo (sa-east-1)
  5. Clique em "Create project"
  6. Copie a Connection String que aparece (começa com postgresql://...)
Guarde essa Connection String! Você vai usar como DATABASE_URL no próximo passo.
2

Obter API Key da OpenAI

2 min

🔑 Abrir OpenAI API

  1. Faça login (ou crie conta)
  2. Clique em "Create new secret key"
  3. Nome: gestor-cs
  4. Copie a chave (começa com sk-...)
  5. Adicione crédito: Billing → Add credit ($15 é suficiente para gerar todas as 18.000 questões)
3

Configurar o Projeto

5 min

Abra o PowerShell e navegue até a pasta do projeto:

Navegar até o projeto:
cd "$HOME\OneDrive\Desktop\cadernos 2026 agente\gestor-estudos-cs"
Instalar dependências:
npm install
Criar arquivo .env (cole os valores reais):
Copy-Item .env.example .env

Abra o arquivo .env com o Bloco de Notas e preencha:

VariávelValor
DATABASE_URLA connection string do Neon (passo 1)
JWT_SECRETUma frase secreta qualquer (ex: "minha-plataforma-cs-2026")
OPENAI_API_KEYA chave sk-... da OpenAI (passo 2)
NEXT_PUBLIC_APP_URLhttp://localhost:3000 (mude depois para seu domínio)
4

Criar Tabelas no Banco

1 min
Criar tabelas no PostgreSQL:
npx prisma db push
Popular com as 29 disciplinas e editais:
npm run seed
Deve aparecer: "✅ 29 disciplinas criadas" e "✅ TJ-SP, TJ-MG, MP-SP"
5

Testar Localmente

2 min
Iniciar o servidor local:
npm run dev

Abra no navegador: http://localhost:3000

Você verá a tela de login! Crie uma conta e explore o Dashboard, Questões, Ranking, Editais e Desempenho.
6

Gerar 18.000 Questões com IA

~2 horas (automático)

Este script lê todos os seus 109 PDFs e gera questões automaticamente:

Processar todos os PDFs da pasta pai:
npm run process-pdfs -- ".."

O script vai:

  1. Encontrar os 109 PDFs nas 29 pastas de disciplinas
  2. Extrair texto página por página
  3. Enviar para GPT-4o-mini gerar questões
  4. Salvar no banco com tópico, dificuldade, explicação e referência à página
Esse processo leva ~2 horas e custa ~$15 na API da OpenAI. Você pode parar e continuar depois — ele pula páginas já processadas.
Estimativa: ~750 questões por caderno × 24 cadernos = ~18.000 questões no total!
7

Publicar na Vercel (Deploy)

5 min

Opção A — Via GitHub (recomendado):

Inicializar git e criar repo:
git init && git add . && git commit -m "Gestor de Estudos CS v1.0"
gh repo create gestor-estudos-cs --private --source=. --push

🚀 Abrir Vercel

  1. Conecte sua conta GitHub
  2. Selecione o repositório gestor-estudos-cs
  3. Nas Environment Variables, adicione: DATABASE_URL, JWT_SECRET, OPENAI_API_KEY
  4. Clique Deploy
Em ~2 minutos você terá um link tipo: gestor-estudos-cs.vercel.app

Opção B — Via CLI:

npm i -g vercel
vercel --prod
8

Configurar Domínio Personalizado

10 min

Para ter um endereço como estudos.cadernossistematizado.com:

  1. Na Vercel, vá em Settings → Domains
  2. Adicione: estudos.cadernossistematizado.com
  3. No seu provedor de DNS, crie um CNAME apontando para cname.vercel-dns.com
  4. Aguarde propagação (até 48h, geralmente 5 min)
HTTPS é automático na Vercel! Seu site já estará com certificado SSL.
